## **BigQuery**

### **Caso de Uso**

1. **Análise de Big Data:**
Analisar uma grande quantia de dados para extrair seus insights.

2. **Business Intelligence (BI):** 
Gera relatórios e dashboards para a visualização e análise de dados empresariais.


3. **Processamento de Dados em Tempo Real:** Analisa os dados em tempo real para o supervisionamento e respostas rápidas a eventos.

4. **Data Warehousing:** 
Armazenamento e gerenciamento de dados históricos para análises duradouras e geração de relatório.

<br>

### **Aplicações**

Suas as aplicações variam de diversas áreas como:
saúde, mídia, financeiro, comércio e até mesmo o entretenimento.

<br>

Resumidamente, o BigQuery possui uma variada funções por ser uma ferrameta potente para análise de um grande volume de dados, tendo uma ecalabilidade eficiênte, desempenho e facilidade de uso.

### **Usos Comuns**

- **Análise de Dados em Tempo Real:** Usando Spark Streaming, se faz possível processar e analisar dados em tempo real que vem de fontes como Kafka, Flume, e Kinesis.

- **Machine Learning:** MLlib, a biblioteca de machine learning do Spark, oferece uma ampla gama de algoritmos para classificação, regressão, clustering e filtragem colaborativa.

- **ETL (Extract, Transform, Load):** Spark é amplamente usado para processos de ETL, movendo e transformando dados entre diferentes sistemas.

- **Análise de Big Data:** Com Spark SQL, os dados podem ser consultados utilizando uma linguagem SQL, facilitando a análise e exploração de grandes conjuntos de dados.

- **Processamento de Grafos:** GraphX, a API de grafos do Spark, permite o processamento e análise de dados estruturados em grafos, como redes sociais ou redes de transporte.
